## 📌 Project Overview
This is an end-to-end Data Analytics project that analyzes 1,000 retail transactions (Jan 2023 - Jan 2024) to understand revenue trends, product category performance, and customer demographics. 

The project covers the complete pipeline:
1. **Data Analysis:** Cleaning data and generating insights using Python.
2. **Backend:** Building a REST API using Python Flask.
3. **Frontend:** Designing an interactive UI to visualize live data from the API.

## 🛠️ Tech Stack
*   **Data Analysis:** Python (Pandas, NumPy, Matplotlib, Seaborn) on Google Colab
*   **Backend:** Python (Flask, Flask-CORS)
*   **Frontend:** HTML, Tailwind CSS, Chart.js, JavaScript
*   **Dataset:** Kaggle Retail Sales Dataset (1,000 records)

## 📊 Key Results (KPIs)

## 🚀 How to Run Locally
To test this project on your own machine:
1. Clone this repository.
2. Install backend dependencies: `pip install flask flask-cors`
3. Run the backend server: `python app.py`
4. Open `bajpai.html` in your browser to view the dashboard connected to the live API.

## 💡 Key Insights
1. Electronics leads revenue generation (34.4%), but categories are closely balanced.
2. May 2023 was the best performing month (₹53,150) and September the weakest (₹23,620).
3. High-priced items (₹300+) drive 88.4% of revenue despite being only 40.3% of units sold.
4. Revenue is split fairly evenly between female (51.1%) and male (48.9%) customers.
